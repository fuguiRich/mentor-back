# 导师管理服务系统 · 功能需求清单

> 版本：v1.0 ｜ 日期：2026-10-20 ｜ 状态：初稿

---

## 一、总体业务目标

建立校内外创新创业导师资源库，实现导师预约、指导记录、考核评价一体化管理，打通师生对接通道。

业务核心流程分为三类：

1. **导师入驻审核**：导师自主填报 / 管理员录入 → 二级学院审核 → 创新创业学院审核
2. **导师预约指导**：学生发起预约 → 导师确认指导 → 填写指导记录 → 学生评价打分 → 二级学院初评 → 双创学院终评 → 考核结果归档

---

## 二、学生端需求

### 2.1 导师资源检索
- 检索筛选条件：导师姓名、所属单位（校内 / 校外）、研究领域、指导方向、职称资质、可指导时段
- 查看内容：导师个人简介、研究成果、指导经历
- 展示字段：学号、姓名、学院、专业、行政班级、联系电话

### 2.2 预约管理
- **预约类型**可选：双创竞赛指导、科研项目指导、创业实践指导、论文 / 专利指导、其他双创指导
- **预约填报字段**：指导主题、拟咨询问题、期望指导时间、对接方式（线上 / 线下）
- **预约状态跟踪**：待导师确认 / 已确认 / 已拒绝 / 已完成
- 导师拒绝预约时可查看拒绝原因，支持重新发起预约

### 2.3 材料上传
- 上传预约辅助材料（项目计划书、竞赛备赛资料等）
- 支持图片、PDF，多份上传

### 2.4 指导记录确认
- 核对导师填写的指导记录（指导时间、内容、建议）
- 无异议确认提交；有异议填写反馈申请复核

### 2.5 导师评价
- 对已完成指导进行评价
- 评价维度：指导态度、专业能力、指导效果
- 支持评分 + 文字评价
- 评价结果同步至导师考核档案

### 2.6 记录查询与导出
- 按时间段、指导类型筛选个人预约记录、指导记录、评价记录
- 导出个人指导档案

## 三、导师端需求（校内 / 校外通用）

### 3.1 个人信息维护
- 完善个人简介、研究领域、指导成果
- 上传职称证书、行业资质佐证材料
- 信息修改需经双创学院审核生效
- 展示字段：导师姓名、所属单位、职称 / 资质、联系电话、指导方向
- 校外导师额外展示：合作单位、社会任职

### 3.2 指导时段管理
- 按周设置固定可指导时段
- 支持临时修改、关闭时段

### 3.3 预约申请处理
- 对学生预约执行确认 / 拒绝 / 调整时间操作
- 操作时填写相关意见

### 3.4 指导记录填报
- 填写学生信息、实际指导时间、指导方式、核心指导内容、后续指导建议

### 3.5 过程材料上传
- 上传课件、交流笔记、项目修改意见等材料
- 图片、PDF 格式，支持多份上传

### 3.6 数据查看
- 实时查看预约处理进度、指导记录汇总、学生评价结果
- 查看个人考核指标完成情况、指导成果归档信息

### 3.7 指导数据统计
- 按时间段、指导类型统计指导学生数量、指导次数、累计指导时长
- 导出个人指导工作台账

### 3.8 考核申诉
- 查看学生评价汇总、学院初评意见、双创学院终评结果
- 对考核结果有异议，提交申诉说明

## 四、二级学院管理员 & 创新创业学院管理员 共有需求

### 4.1 导师资源库统计
- 查看导师资源库信息统计，导出统计表和名单
- 二级学院仅统计本院；双创学院管理员按学院 / 全校统计
- 统计项：入驻导师总数、校内 / 校外导师数量、各指导方向导师分布、审核通过 / 未通过导师数、活跃 / 非活跃导师数

### 4.2 师生预约情况统计
- 查看师生对接预约统计，导出表格名单
- 状态包含：待确认 / 已确认 / 已拒绝 / 已完成
- 二级学院统计本院；双创学院管理员按学院 / 全校统计

### 4.3 业务审核
- 审核导师入驻 / 信息修改申请、学生预约复核申请
- 可选择通过 / 不通过；不通过需填写审核意见并退回用户修改
- 审核界面字段顺序：导师 / 学生基本信息、申请类型、填报内容、上传佐证材料、申请时间、联系方式

### 4.4 材料下载预览
- 下载、在线查看导师 / 学生上传佐证材料（图片、PDF）
- 支持保存至本地

### 4.5 工作进度追踪与提醒
- 实时追踪导师指导工作进度
- 查看预约处理、指导记录填写、考核评价节点
- 对未处理预约、未填写指导记录的导师发送提醒

### 4.6 指导工作数据统计
- 按导师个人、学院、全校维度统计
- 可按指导类型、时间段筛选
- 导出指导次数、时长、学生数、成果数等统计结果

### 4.7 档案归档检索
- 导师指导成果、考核档案归档留存
- 审核通过材料统一归档
- 可按导师、学院、指导类型、时间段检索查询
- 归档材料长期保存

## 五、二级学院管理员 特有需求

### 5.1 导师入驻审核
- 审核本院校内导师、本院合作校外导师入驻申请、信息修改申请
- 核对资质证明、指导方向
- 审核结果同步到双创学院端口

### 5.2 导师考核初评
- 依据学生评价、指导工作量（次数、时长、学生数）、本院双创成果（竞赛获奖、项目立项等）进行初评
- 填写初评意见、初评等级，提交双创学院终评

### 5.3 师生对接监控
- 查看本院师生对接情况
- 统计预约成功率、指导完成率
- 对多次预约失败、未完成指导的师生，支持线下协调提醒

### 5.4 成果关联归档
- 将本院学生双创成果与对应指导导师关联
- 同步至导师考核档案、学生实践学时档案

### 5.5 报表导出
- 导出本院导师资源表、指导工作统计表、考核初评表
- 包含导师基础信息、指导数据、考核结果

## 六、创新创业学院管理员 特有需求

### 6.1 后台数据修改
- 修改导师 / 学生填报字段（导师入驻信息、学生预约信息等）
- 修改后同步至所有相关端口
- 完整保留修改记录（修改人、修改时间、修改内容）

### 6.2 考核终评
- 审核二级学院提交的导师初评结果
- 结合全校指导成果、导师综合表现终评
- 审核不通过填写意见退回二级学院重评
- 审核通过则考核结果生效并同步全端口

### 6.3 全校考核统计
- 查看全校导师考核评价
- 按学院、导师类型（校内 / 校外）、指导方向统计考核等级（优秀 / 合格 / 不合格）分布
- 导出统计表与名单

### 6.4 导师资源库统筹管理
- 统筹全校导师库
- 调整入驻审核流程、考核评价标准
- 查看各审核节点进度，提醒审核滞后、考核未完成的二级学院
- 支持导师分类管理（指导方向、领域、校内校外标签）
- 对长期无指导导师执行冻结 / 移出，保留操作记录
- 支持单条录入、批量导入校内外导师信息

### 6.5 归档材料管理
- 统一管理归档的导师成果、考核档案
- 支持批量导出、分类整理
- 按规定清理过期非核心材料

### 6.6 系统参数配置
- 配置系统核心参数：预约有效期、指导记录提交时限、考核指标权重
- 按学期 / 年度更新导师入驻标准、考核评分规则

### 6.7 跨系统数据互通
- 打通与学生创新创业实践学时申报系统的数据通道
- 学生双创成果自动作为实践学时认定佐证材料

### 6.8 数据分析报表
- 生成全校导师管理数据分析报表
- 包含：导师库规模变化、师生对接成功率、导师指导效果、考核结果分布
- 支撑导师队伍建设决策

## 附录：角色权限速览

| 角色 | 核心权限 |
| --- | --- |
| 学生 | 检索导师、发起预约、上传材料、确认指导记录、评价导师、查询导出个人档案 |
| 导师（校内 / 校外） | 维护信息、管理时段、处理预约、填报记录、上传材料、数据统计、考核申诉 |
| 二级学院管理员 | 本院导师入驻审核、考核初评、师生对接监控、成果关联归档、报表导出 |
| 创新创业学院管理员 | 后台数据修改、考核终评、全校考核统计、资源库统筹、归档管理、参数配置、数据互通、分析报表 |
