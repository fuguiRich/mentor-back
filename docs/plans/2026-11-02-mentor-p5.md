**精确值**
- `ASSESSMENT_PERIOD_PATTERN = /^\d{4}-[12]$/`
- `LEGACY_ASSESSMENT_PERIOD_PATTERN = /^\d{4}$/`
- `currentPeriod(now = new Date())`：UTC 月份 `<= 6` → `${年}-1`，否则 `${年}-2`
- `periodRange(period)`：
  - `YYYY-1` → `[YYYY-01-01Z, YYYY-07-01Z)`
  - `YYYY-2` → `[YYYY-07-01Z, (YYYY+1)-01-01Z)`
  - `YYYY` → `[YYYY-01-01Z, (YYYY+1)-01-01Z)`（只读兼容）
  - 其他 → **400 / 10001**，文案「考核周期必须是 YYYY-S（S=1/2）」
- `StatsQueryDto.period` 正则 `^\d{4}(-[12])?$`；缺省区间改为
  `periodRange(currentPeriod())`
- 工作台 `currentAssessment` 取 `currentPeriod()`

**判据**
- [ ] 四个边界（`2026-1` / `2026-2` / 跨年 / 非法）单测逐条断言
- [ ] 新建考核只收 `YYYY-S`；`2026` → 400 / 10001
- [ ] 历史 `2026` 的统计查询仍能读出全年区间（只读兼容）
- [ ] 既有考核 / 统计 / 工作台 e2e 全绿（夹具改成学期）

**响应 / 请求**

  `assessment.workload_target_count`、`assessment.achievement_target_count`
- `normalized` 由 `resolveWeights` 计算并随响应回显

**工作进度口径**
- `pendingAppointments`：`appointment.status = 0` 的条数
- `missingRecords`：`status = 1` 且 `requestedTime < now` 且没有指导记录
- `pendingAssessments`：`assessment.period = currentPeriod()` 且
  `status ∈ {0,1}` 的条数
- 只列生效导师（`status = 2`）；学院管理员只看本院

**提醒**
- 请求 `{ type: 'pending-appointments' | 'record-missing' | 'assessment-pending', mentorProfileIds?: string[] }`
- 只对「该类型计数 > 0」的导师发；没有 `SysUser` 的计入 `skipped`
- 标题逐字：`预约待处理提醒` / `指导记录待填写提醒` / `考核待处理提醒`
- 内容逐字：`您有 N 条预约待确认，请及时处理。` /
  `您有 N 条已确认预约尚未填写指导记录，请及时补填。` /
  `您在 {period} 的考核尚未完成，请及时处理。`
- 响应 `{ sent: number; skipped: number }`

**判据**
- [ ] 学院管理员发提醒 → 本院导师收到；跨院导师收不到
- [ ] 消息列表默认按 `createdAt DESC`；`read=0/1` 可筛
- [ ] 标记已读后 `readAt` 非空；再读一次幂等
- [ ] 标记别人的消息 → 404 / 38001（藏存在性）
- [ ] `read-all` 返回 `{ updated }`，第二次为 0

**关联语义（人工，P5-R3）**
- `POST` 可带 `mentorProfileId` 直接关联；也可先建后 `PATCH .../link`

  `student_achievement.mentorId/achievementId/linkedAt/linkedBy` →
  ③ 落一条 `archive_item`（`targetType='StudentAchievement'`、`category='achievement'`、
  `core=0`、`mentorId`、`deptId=学生学院`、保留期 = 今天 + 1825 天）
- 已关联再 link → **409 / 39002**；导师不存在 / 未生效 → **404 / 31102**
- 删除：同事务软删关联的 `Achievement` 与对应归档条目

**判据**
- [ ] 关联后导师 `Achievement` 多一条，考核 `achievementCount` +1
- [ ] 归档条目 `core=0`、保留期 +1825 天、`deptId` = 学生学院

- [ ] 重复 link → 409 / 39002

### Task 61: P5 端到端验收

**Files:** `test/mentor-p5-flow.e2e-spec.ts`、
`.superpowers/sdd/2026-11-02-mentor-p5/task-p5-acceptance.md`

**正链**
1. 建学期 `currentPeriod()` 的考核；`GET /stats/assessments?period=` 命中
2. 造待确认预约 / 逾期未填记录 / 待处理考核 → `GET /work-progress` 三个计数

- N1 学生调 `/work-progress` → 403
- N2 学院管理员给外院导师发提醒 → 403
- N3 重复 link → 409 / 39002
- N4 学生调 `/student-achievements` POST → 403
- N5 非法学期 `2026-3` → 400
- N6 权重全 0 → 400

**判据**：正链七步 + 六条负路径全绿，每步断具体数值。
